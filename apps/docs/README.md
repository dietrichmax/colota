# Colota docs

The site at [colota.app](https://colota.app), built with a pinned [Hugo](https://gohugo.io/) and no npm packages.

```bash
npm start -w @colota/docs   # preview at http://localhost:1313
npm run build -w @colota/docs
npm test -w @colota/docs
```

`apps/docs/AGENTS.md` describes how the site fits together.
